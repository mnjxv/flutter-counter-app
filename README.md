# Flutter Counter App

A simple Flutter counter app with increment, decrement, and reset buttons, a gradient background, and light and dark themes.

## Features

- Increment with the floating action button.
- Decrement (disabled at 0) and Reset buttons.
- Animated number change.
- Material 3 design that follows the system light or dark mode.

## Getting Started

```bash
flutter pub get
flutter run
```

## Running Tests

```bash
flutter test
```
